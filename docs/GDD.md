# 스푼 브레이크 (Spoon Break) 기획서

Oct 26, 2026 · @jiHyun

## 개요

스푼 브레이크(Spoon Break)는 감방 바닥을 숟가락으로 파서 탈옥하는 3D 모바일 클리커다. 말도 안 되게 진화하는 숟가락이 핵심 훅이다. 제목은 프리즌 브레이크 말장난으로, 해외 출시까지 고려했다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 클리커 + 방치형, 강화 |
| 플랫폼 | Android + iOS, 모바일 세로 화면 |
| 그래픽 | 3D 로우폴리, 고정 단면 시점 |
| 대상 | 전 연령이 가볍게 즐기는 캐주얼 |
| 개발 방식 | 바이브 코딩 |
| 볼륨 | 감옥 3개, 숟가락 50단계 (새 3D 모델 13개) |
| 수익 | 보상형 광고 + 배너 + 광고 제거 상품 |

### 참고작 (구조만 참고)

- **Prison Escape Simulator: Dig Out**: 바닥 파기 탈옥, 간수 눈 피하기, 카펫으로 숨기기
- **거지키우기**: 탭으로 재화 벌기, 알바 고용으로 자동 수입
- **ForgeTax**: 강화 수치에 따라 외형이 진화하고, 진화한 외형은 레벨이 떨어져도 되돌아가지 않음. 강화 확률을 화면에 표시

## 핵심 루프

탭으로 휴지를 벌고, 휴지로 숟가락을 강화하고, 강해진 숟가락으로 더 빨리 파서 탈출한다.

1. 감방을 탭해서 휴지를 번다 (동료 죄수가 자동으로도 모아줌)
2. 휴지로 숟가락을 강화한다 (일정 수치마다 외형 진화)
3. 파기 ON 상태에서 숟가락 성능만큼 자동으로 깊이가 늘어난다
4. 간수 예고가 뜨면 파기 OFF로 숨긴다
5. 탈출 깊이에 도달하면 다음 감옥으로 넘어간다

휴지를 숟가락 강화에 쓸지, 동료 죄수에 쓸지 고르는 것이 기본 선택이다.

## 화면 구성

3D 로우폴리, 카메라는 살짝 위에서 비스듬히 내려다보는 각도로 고정한다. 감방을 앞쪽에서 잘라낸 단면처럼 보여주며, 카메라 조작은 없다.

### 분할 화면

- **위**: 감방 고정 (침대, 카펫, 철창). 철창 너머로 간수 예고가 보인다
- **아래**: 지금 파고 있는 굴착면. 캐릭터와 숟가락을 크게 보여준다
- **중간 터널**: 생략 표시로 접어두고, 실제 깊이는 깊이 바로 표시한다
- **탈출 연출**: 접어뒀던 터널을 카메라가 쭉 따라 내려가 바깥으로 빠져나오며 전체 길이를 한 번에 보여준다

감방과 숟가락이 항상 동시에 보여야 하므로 분할 화면을 쓴다. 카메라가 터널을 따라 내려가면 감방이 화면 밖으로 나가 간수 예고를 놓친다.

### UI 배치 (위에서 아래로)

| 위치 | 요소 |
| --- | --- |
| 맨 위 | 배너 광고 |
| 상단 바 | 감옥 이름, 휴지 보유량, 초당 휴지 (배너와 탭 영역 사이 완충) |
| 오른쪽 세로 | 깊이 바 (현재 깊이 / 탈출 깊이) |
| 감방 | 탭 영역 (탭하면 휴지) |
| 굴착면 | 캐릭터, 숟가락 |
| 하단 중앙 | 파기 토글 버튼, 크게 (엄지 위치) |
| 맨 아래 | 탭 메뉴: 숟가락 강화 / 동료 죄수 / 상점 / 설정 |

- 탭 영역과 파기 토글은 확실히 떨어뜨린다. 연타 중 토글을 잘못 누르지 않게 한다.
- 화면 위 UI는 2D 오버레이다.

## 파기와 간수

- **파기 ON**: 수리된 숟가락의 성능만큼 자동으로 깊이가 늘어난다. 숟가락이 부러져 있으면 ON 상태여도 파기는 진행되지 않는다. 클릭은 휴지 벌기 전용이다.
- **파기 OFF**: 카펫으로 덮인 상태. 진행이 멈추고 안전하다.
- **간수 순찰**: 일정 간격으로 오며, 오기 전에 예고가 있다 (발소리, 철창 밖 그림자). 예고를 보고 OFF로 바꾸면 안전하다. 순찰 간격과 예고 길이는 감옥마다 다르다 (감옥 섹션 참고).
- **걸렸을 때**: 판 깊이가 일부 메워진다. 휴지는 뺏지 않는다 (클릭한 노력이 날아가면 클리커의 기본 재미가 상함).
- 간수 페널티는 광고로 면제할 수 없다.

## 재화와 자동 수입

재화는 휴지 하나뿐이다. 유료 재화는 두지 않고, 휴지를 현금으로 팔지도 않는다.

- **클릭**: 감방을 탭하면 휴지 획득
- **동료 죄수 고용**: 휴지를 주고 죄수를 고용하면 자동으로 휴지를 모아다 준다. 레벨업할수록 초당 휴지 증가 (종류와 성장 방식은 감옥 3개 완성 후 추가)
- **앱을 꺼둔 동안**: 동료 죄수가 휴지를 계속 모아둔다 (상한 시간 있음). 파기는 진행되지 않는다 (간수 요소를 지키기 위해)
- **다시 켰을 때**: 모아둔 휴지를 받는다. 광고를 보면 2배

## 숟가락 강화

숟가락은 휴지로 강화하고, 일정 강화 수치마다 외형이 진화한다. 이 게임의 핵심 훅이므로 이름·연출·외형에 가장 많이 투자한다.

- **시작과 최저 단계**: 1단계로 시작하며, 강화 하락으로 1단계 아래로 내려가지 않는다.
- **강화 상한**: 감옥별 강화 상한은 없다. 현재 콘텐츠의 최종 단계는 50단계다. 아래 감옥별 단계 구분은 외형 테마 구분이며 강화 제한이 아니다.
- **진화**: 특정 강화 수치에 도달하면 외형이 바뀐다. 진화한 외형은 레벨이 떨어져도 되돌아가지 않는다.
- **이름**: 티스푼처럼 평범한 건 쓰지 않는다. 처음부터 개성 있게 시작해서 뒤 감옥으로 갈수록 말도 안 되게 올라간다.
- **정점 연출**: 각 감옥의 마지막 단계(16, 33, 50)를 얻으면 숟가락을 화면 가운데 띄워 회전시키는 전용 컷인을 넣는다.
- **확률 표시**: 강화 확률은 처음부터 화면에 항상 표시한다.

### 강화 결과

| 결과 | 내용 |
| --- | --- |
| 성공 | 레벨 +1 |
| 유지 | 휴지만 소모, 레벨 그대로 |
| 하락 | 레벨 -1, 최저 1단계 (진화 외형은 유지) |
| 부러짐 | 수리 전까지 파기 불가. 휴지로 수리하거나 보상형 광고를 보고 즉시 수리. 광고 제거 구매자는 광고 없이 무료로 즉시 수리 |

부러짐은 중복 발생하지 않으며, 시간이 지나도 자동으로 수리되지 않는다. 파괴는 넣지 않는다. 부러져도 숟가락을 잃지 않으며, 수리하면 다시 파기를 진행할 수 있다.

### 구간별 확률 (예시, 프로토타입에서 조정)

| 강화 구간 | 성공 | 유지 | 하락 | 부러짐 |
| --- | --- | --- | --- | --- |
| 1\~5강 | 90% | 10% | - | - |
| 6\~10강 | 60% | 40% | - | - |
| 11\~15강 | 40% | 50% | 10% | - |
| 16강 이상 | 25% | 55% | 15% | 5% |

- 올라갈수록 성공은 떨어지고 유지가 올라간다. 하락과 부러짐은 높은 구간에서만 등장한다.
- 광고 "성공률 +10%"는 성공에 더하고 유지에서 뺀다. 하락·부러짐 확률은 건드리지 않는다.
- 광고 제거 구매자는 +10%가 항상 적용되므로, 확률 화면에 "광고 제거 적용 중"으로 올라간 확률을 표시한다.

## 감옥

탈출하면 다음 감옥으로 넘어가는 이어가기형이다. 탈출 조건은 해당 감옥의 목표 깊이 도달뿐이며, 특정 숟가락 단계나 진화 외형을 요구하지 않는다. 숟가락 강화 레벨과 진화 외형은 유지되고, 다음 감옥은 땅이 더 단단해진다. 감옥 데이터(필요 깊이, 땅 단단함, 간수 강도)만 추가하면 콘텐츠가 늘어나는 구조다.

환생형(전부 초기화)이 아닌 이유: 애써 얻은 숟가락이 사라지면 수집 재미가 끊긴다.

### 마지막 감옥 탈출 후 다시 플레이

- 마지막 감옥 탈출 후 1감옥부터 다시 플레이할 수 있다.
- 숟가락 강화 레벨·진화 외형·보유 휴지·고용한 동료와 그 성장 상태는 유지한다.
- 감옥 진행과 깊이만 초기화한다. 숟가락을 1단계로 되돌리지 않는다.

### 감옥 3개 테마

그 감옥에서 구할 수 있는 물건이 숟가락이 된다는 것을 기준으로 맞춘다. 난이도는 주로 간수로 올라간다.

| 항목 | 1감옥: 동네 유치장 | 2감옥: 블랙록 교도소 | 3감옥: 마왕성 지하 감옥 |
| --- | --- | --- | --- |
| 숟가락 단계 | 1\~16 | 17\~33 | 34\~50 |
| 분위기 | 경찰서 한쪽, 형광등, 낡은 철제 침대 | 바다 위 절벽 섬, 서치라이트 | 횃불과 보라빛 마력, 쇠사슬 |
| 숟가락 출처 | 경찰서 식당, 집밥 물건 | 공작실, 공사장 도구 | 마왕의 보물창고 |
| 땅 | 흙 → 자갈 | 암반 → 철광석 | 용암층 → 마력 결정 |
| 간수 | 졸린 순경 | 엄격한 교도관 | 그림자 마물 (눈만 빛남) |
| 순찰 | 간격 길고 규칙적, 예고 김 | 간격 짧고 불규칙 | 불규칙 + 가끔 예고 짧은 기습 |
| 탈출 지점 | 동네 공원 화단 | 절벽 아래 바다 동굴 | 성 밖, 용의 둥지 |

- 1감옥은 예고가 길어서 파기 토글을 배우는 튜토리얼 역할이다.
- 3감옥 기습은 억울하지 않도록 눈이 빛나는 전용 신호를 따로 준다.
- 마지막 탈출 지점은 용의 둥지이며, 50단계 "한여름밤의 용"과 테마가 이어진다. 마지막 탈출에도 50단계 달성을 요구하지 않는다.

## 광고와 수익

| 종류 | 자리 | 내용 |
| --- | --- | --- |
| 보상형 | 앱 다시 켰을 때 | 오프라인 휴지 2배 |
| 보상형 | 강화 직전 | 성공률 +10% |
| 보상형 | 숟가락 부러졌을 때 | 즉시 수리 |
| 배너 | 메인 화면 맨 위 | 상단 바 위쪽 |
| 배너 | 메뉴 화면 | 숟가락 강화, 동료 죄수 등 |
| 전면 | 없음 |  |

### 유료 상품

- **광고 제거** 하나만 판매한다. 구매하면 배너가 사라지고, 보상형 광고 혜택(오프라인 2배, 성공률 +10%, 즉시 수리)이 광고 없이 자동 지급된다.
- 휴지는 현금으로 팔지 않는다. 유료 재화도 없다.

### 배치 원칙

- 메인 배너는 하단에 두지 않는다. 파기 토글·탭 메뉴 근처라 실수 클릭이 생기고, 실수 클릭을 유도하는 배치는 광고 플랫폼 정책 위반으로 계정 정지 사유가 될 수 있다.
- 광고 제거 구매자는 부러짐 수리가 항상 무료라 부러짐 부담이 거의 없다. 유료 상품이 하나뿐이라 구매 가치를 확실히 하는 쪽으로 정했다.

## 주의사항과 이후 작업

### 주의사항

- **참고작에서 가져오는 건 구조만**: ForgeTax의 검 이름·외형, Dig Out의 에셋 등은 그대로 쓰지 않는다. 저작권 문제와 스토어 신고 대상이 될 수 있다.
- **아동 대상 앱으로 등록하지 않는다**: 아동 대상으로 등록하면 스토어 아동 정책이 적용되어 맞춤형 광고가 막히고 광고 단가가 크게 떨어진다.
- **확률 표시 유지**: 휴지를 현금으로 팔지 않아 확률 공개 법 대상은 아니지만, 플레이어가 덜 억울하도록 표시는 유지한다.
- **제목 중복 확인**: 출시 전 구글 플레이와 앱스토어에서 "스푼 브레이크 / Spoon Break" 같은 이름이 있는지 직접 확인한다.
